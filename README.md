# Robert Chappell CS499 Portfolio

Professional Computer Science Capstone portfolio built with React, Vite, plain
CSS, and React Icons.

## Development

```bash
npm install
npm run dev
```

## Build for GitHub Pages

```bash
npm run build
```

The Vite source lives in `app/`. The build output is generated in `dist/`, then
the deployable `index.html` and `assets/` are exported to the repository root so
the existing GitHub Pages configuration can continue serving the site from the
`main` branch root.
